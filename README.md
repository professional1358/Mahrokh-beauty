# ماه‌رخ لایت — فروشگاه تلگرامی کم‌هزینه

این نسخه عمداً بدون بک‌اند، دیتابیس، درگاه پرداخت و رباتِ همیشه‌روشن ساخته شده است. سایت را رایگان روی GitHub Pages منتشر می‌کنید و مشتری سبد خریدش را به شکل متن آماده در چت تلگرام فروشگاه باز می‌کند؛ مشتری فقط دکمه Send تلگرام را می‌زند.

## امکانات
- طراحی فارسی، راست‌چین، واکنش‌گرا و لوکس صورتی
- محصولات، دسته‌بندی، قیمت، تصویر و برچسب
- سبد خرید با تغییر تعداد و محاسبه جمع کل
- ارسال متن کامل سفارش به چت تلگرام مدیر
- بدون درگاه، سرور، دیتابیس یا هزینه تراکنش

## تنظیم آیدی تلگرام فروشگاه
فایل `config.js` را باز کنید و این مقدار را عوض کنید:
```js
const TELEGRAM_USERNAME = "YOUR_TELEGRAM_USERNAME";
```
مثلاً اگر آیدی شما `mahrokh_shop` است، فقط `mahrokh_shop` را بدون @ وارد کنید. مشتری پس از زدن «ارسال سفارش به تلگرام» وارد چت شما می‌شود و متن سفارش آماده است؛ برای ارسال نهایی باید دکمه ارسال را در تلگرام بزند.

## ویرایش محصولات و عکس‌ها
1. در GitHub وارد repository شوید.
2. فایل `products.json` را باز و روی Edit بزنید.
3. نام، دسته‌بندی، قیمت، توضیح، نام عکس و برچسب را تغییر دهید.
4. برای عکس جدید، در پوشه `images` فایل تصویر را آپلود کنید و مسیر آن را در فیلد `image` بنویسید.
5. Commit changes را بزنید؛ پس از چند لحظه سایت به‌روزرسانی می‌شود.

ساختار هر محصول:
```json
{
  "id": 5,
  "name": "نام محصول",
  "category": "آرایش",
  "price": 250000,
  "description": "توضیح کوتاه",
  "image": "images/product-5.jpg",
  "tag": "جدید"
}
```
دسته‌بندی‌های پیش‌فرض: `مراقبت پوست`، `آرایش`، `مو`. شناسه هر محصول (`id`) باید یکتا باشد. قیمت را عددی و به تومان وارد کنید.

## انتشار رایگان روی GitHub Pages
1. فایل‌های پروژه را در یک repository آپلود کنید.
2. Settings → Pages را باز کنید.
3. در Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
4. Branch را `main` و پوشه را `/ (root)` بگذارید و Save کنید.
5. آدرس سایت شما پس از انتشار شبیه `https://USERNAME.github.io/REPOSITORY/` خواهد بود.

## نکته مهم درباره تجربه تلگرام
برای باز شدن مستقیم چت مدیر، `TELEGRAM_USERNAME` باید آیدی عمومی معتبر داشته باشد. این روش از API ربات استفاده نمی‌کند و پیام را بی‌اجازه ارسال نمی‌کند؛ متن سفارش را آماده می‌کند و خود مشتری باید ارسال را تأیید کند. بنابراین توکن ربات یا سرور لازم نیست.

## محدودیت شفاف
این نسخه پنل مدیریت داخل سایت ندارد؛ برای کمترین هزینه، ویرایش محصولات از خود GitHub انجام می‌شود. اگر پنل ویرایش داخل سایت بخواهید که تغییرات را برای همه مشتری‌ها ذخیره کند، به بک‌اند و فضای ذخیره‌سازی نیاز است و ممکن است هزینه میزبانی داشته باشد.
